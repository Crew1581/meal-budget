# Каталог «Пятёрочки»: происхождение и обновление

## Состояние сбора

Попытка сбора: **2026-10-13**, октябрь 2026. `5ka.ru` вернул HTTP 403 на
главной и двух официальных карточках. Содержимое карточек не получено;
CAPTCHA, авторизация и ограничения не обходились. Поисковая выдача использована
только для поиска URL, не как доказательство значений.

**Фактически проверенных товаров: 0; реальный снимок `data/5ka-products.json` пуст.**
Версия: `5ka-2026-10-13-blocked-v1`. Это версия состояния заблокированного сбора,
не версия успешно собранного снимка цен. Регион Москва — целевой, **не подтвержденный**;
адрес и магазин не выбраны. Ни московских, ни офлайн-цен не зафиксировано.
Нет проверенных цены, массы или КБЖУ, поэтому записи по этим URL не включены
даже как подтвержденные товары-кандидаты.

| <https://5ka.ru/product/khlopya-ovsyanye-russkiy-produkt-gerkules-traditsi--6752> | Открытие карточки, найденной поиском | HTTP 403 | Нет |

Это таблица **попыток доступа**, не подтверждение товаров, цен или пищевой ценности.
Время проверки конкретных фактов не присваивается: факты не удалось проверить.
При успешном сборе таблица дополняется по каждому новому product_id: URL карточки,
отдельный URL КБЖУ, фактическое `checked_at` с часовым поясом, условия и география.

## Правила включения

1. Открыть официальную карточку 5ka.ru, проверить конкретные марку, вариант,
   состав и идентификатор сети, если опубликован. Сохранять только факты и ссылки,
   не копировать изображения, рекламные описания или страницы целиком.
2. Цена в рублях за **одну фиксированную упаковку**, доступная без карты,
   покупки нескольких штук и других специальных условий. `price` — Decimal.
   Неясная, карточная или «от двух штук» цена не попадает в активный каталог.
   Акция допустима только при проверенных условиях для одной упаковки без карты;
   сохраняются опубликованные условия и даты, неизвестные даты остаются null.
3. В `provenance.price`: URL, `checked_at` (ISO timestamp с offset),
   `channel=online_delivery|offline_store`, `price_type`, условия и период.
   `region_confirmed=false`, `region=null`, `store=null`, если выбор не проверен.
   Подтвержденный регион не означает подтвержденный конкретный магазин.
   Офлайн-цена требует проверенного магазина; онлайн-доставка не называется офлайн-ценой.
4. В `provenance.nutrition`: отдельный URL и время проверки КБЖУ конкретного товара
   на 100 г. Главный источник — сеть. При отсутствии данных допустим официальный
   производитель **того же товара** с проверяемым совпадением марки, варианта и
   состава. Нельзя заполнять из памяти или средними значениями ингредиента.
5. `state=dry|raw|cooked` соответствует опубликованным данным, не названию блюда.
   Упаковка и используемые граммы должны относиться к той же массе продукта.
   Непроверенное состояние, масса или съедобный выход — причина не включать товар.
6. Схема проверяет структуру, а **не достоверность страницы**. Даже валидная запись
   требует ручной сверки источника. Статус остается `demo_unverified`: нет гарантии
   актуальной цены и наличия в конкретном магазине. Это не цены «на весь октябрь».

## Охват и кандидаты будущих единиц

Все целевые категории пока отсутствуют из-за HTTP 403: крупы/макароны, яйца,
мясо/рыба, молочные продукты, бобовые, овощи, фрукты, растительное масло.
Цель 30–40 записей не достигнута; количество не заменяет качество доказательств.

После восстановления доступа отдельно регистрировать проверенные кандидаты:

| Тип кандидата, не собранные товары | Почему не включать в граммовую модель |
| --- | --- |
| Яйца «10 шт.» | Число штук не дает точного веса съедобной части |
| Весовые овощи, фрукты, мясо/рыба | Цена за кг не является ценой фиксированной упаковки |
| Молоко, масло и другие упаковки в мл/л | Нет неявного преобразования объема в массу |
| Консервы с жидкостью, продукты с костями/кожурой | Масса нетто может не совпадать с массой, к которой относятся КБЖУ |

Сейчас **конкретных проверенных кандидатов нет**. При доступном сборе сохранять
здесь название, URL, точную единицу, опубликованные факты и причину исключения;
не придумывать массу яйца, плотность жидкости или выход слитого продукта.
Расчетное ядро и единицы ради охвата категорий не расширялись.

## Совместимость ID

Прежние `oats`, `buckwheat`, `chicken` были синтетическими demo-ингредиентами,
а не конкретными товарами сети. Их прежние значения сохранены в demo-каталоге
`data/products.json` (`demo-meal-3-v1`, `synthetic_demo`) и отдельно в неизменяемых
расчетных fixtures `tests/fixtures/products.json` (`synthetic-meal-3-v1`).
Обычный запуск по умолчанию обслуживает **demo**, явно предупреждая об этом;
он не зависит от доступности реального снимка. Для реального снимка требуется
`CATALOG_PATH=data/5ka-products.json`. Автоматического переключения на demo нет:
пустой реальный снимок дает unknown_product_id для старого меню и catalog_unavailable
для генерации. Поврежденный выбранный каталог прерывает startup, не подменяется.
При сборе создавать новые ID конкретных товаров, например по ID сети;
не присваивать прежним ID новую марку, массу или КБЖУ. Fixture не источник веб-данных.

## Порядок обновления

1. Получить обычный разрешенный доступ к карточкам; при блокировке остановить сбор.
2. Выбрать Москву и адрес/магазин, если сайт позволяет, проверить выбор;
   иначе сохранить неподтвержденную географию. Зафиксировать канал цены.
3. Проверить цену, упаковку, состояние и КБЖУ; отдельно зарегистрировать кандидатов.
4. Записать реальные timestamps источников и новую неизменяемую версию снимка
    в `data/5ka-products.json`. Не переносить старое время на новую проверку.
5. Обновить таблицу источников и охват, проверить уникальные ID и загрузку схемы.
6. Подготовить по новой версии анкеты и **ручные свидетельства выполнимости**,
   пересчитать их ядром. Проверить примеры, тесты, документацию и контейнер.
7. Перезапустить API: каталог загружается в lifespan, hot reload данных нет.

**Снимок онлайн-каталога не живая корзина.** Он не резервирует товар, не проверяет
наличие, адрес доставки, персональные цены или кассу магазина. Остатки упаковок
в расчете — арифметические, не прогноз срока хранения. Вода в шагах не покупается
и не учитывается в КБЖУ; остальные пищевые ингредиенты должны иметь ID каталога.
